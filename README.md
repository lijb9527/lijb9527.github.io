# 德州扑克多人在线游戏

一个支持多人联机的德州扑克游戏，使用 Node.js + Socket.io + HTML5 实现。

## 功能特性

- 支持多人实时在线对战
- 完整的德州扑克规则
- 实时同步游戏状态
- 支持弃牌、过牌、跟注、加注等操作
- 自动计算牌型和胜负
- 筹码管理系统
- 精美的游戏界面

## 安装运行

### 前置要求

- Node.js (v14 或更高版本)

### 安装步骤

1. 进入项目目录
```bash
cd texas-holdem
```

2. 安装依赖
```bash
npm install
```

3. 启动服务器
```bash
npm start
```

4. 在浏览器中访问
```
http://localhost:3000
```

## 游戏玩法

1. 输入你的名字进入游戏
2. 至少需要2名玩家才能开始游戏
3. 点击"开始游戏"按钮开始新的一局
4. 使用操作按钮进行游戏：
   - 弃牌：放弃本局
   - 过牌：不下注，继续游戏
   - 跟注：跟随当前最高下注
   - 加注：提高下注金额
5. 游戏会自动判断胜负并分配筹码

## 牌型说明

游戏支持完整的德州扑克牌型判断，从高到低依次为：
1. 皇家同花顺
2. 同花顺
3. 四条
4. 葫芦
5. 同花
6. 顺子
7. 三条
8. 两对
9. 一对
10. 高牌

## 技术栈

- 后端：Node.js + Express
- 实时通信：Socket.io
- 前端：HTML5 + CSS3 + JavaScript

## 配置

可以在 `server.js` 中修改以下配置：

- `smallBlind`: 小盲注（默认 10）
- `bigBlind`: 大盲注（默认 20）
- 初始筹码：默认 1000

## 注意事项

- 游戏需要在服务器环境中运行，直接打开 HTML 文件无法使用
- 支持 2-8 名玩家同时游戏
- 游戏数据在服务器重启后会重置
